## 📱 Shadowrocket / Quantumult X 使用说明

LinkCube 官方目前提示：

> **Shadowrocket（小火箭）与 Quantumult X 以往的导入方式已不适用，请改用「托管」模式接入。**

也就是说，现在建议直接将**订阅配置文件**导入客户端，而不是简单地将节点作为普通订阅导入。

### 导入前注意事项

#### 1. 只需复制订阅链接

复制自己的订阅链接，然后按照客户端的托管/配置文件方式进行导入。

**不要点击「重置订阅」按钮。**

#### 2. 导入前关闭代理

获取配置时，建议使用正常的国内网络环境。

请先关闭设备上正在运行的代理软件，包括：

* VPN / 代理软件
* 系统代理
* TUN 模式
* 其他网络代理工具

不要在已经连接代理的情况下获取或导入配置。

#### 3. 使用正常本地网络

建议直接使用：

* 家庭宽带
* 手机移动网络

不建议使用海外 IP 或云服务器网络进行操作，例如阿里云、腾讯云等服务器网络。

#### 4. 不要通过 QQ / 微信转发订阅链接

**订阅链接请自行复制和使用。**

不要将完整订阅链接发送到 QQ、微信等聊天工具中。部分平台可能会对链接进行拦截、修改或安全处理，从而导致订阅链接无法正常使用。
